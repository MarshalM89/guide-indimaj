# المصادقة الثنائية (MFA)

## ما هي المصادقة الثنائية؟ { #presentation }

لحماية حسابك في INDIM@J بشكل أفضل، أصبح الدخول يتم **على مرحلتين**:

- **ما تعرفه**: كلمة المرور، كالمعتاد؛
- **ما تملكه**: هاتفك، الذي يعرض رمزاً من **6 أرقام**.

حتى لو عرف شخص آخر كلمة المرور الخاصة بك، لن يستطيع الدخول إلى حسابك بدون هاتفك.

يظهر الرمز في تطبيق مجاني اسمه **Google Authenticator**، ويتغير كل 30 ثانية.

!!! darija "بالدارجة"
    بحال الكود اللي كيجيك فالتيليفون ملي كتخلص بالكارط فالأنترنيت: كتدخل المودپاس ديالك، ومن بعد كتكتب الكود اللي كيبان فالتطبيق.

### المراحل باختصار { #presentation-1 }

1. **تثبيت** تطبيق Google Authenticator على هاتفك (مرة واحدة).
2. **تفعيل** المصادقة الثنائية بمسح رمز QR (مرة واحدة).
3. **تسجيل** الرموز الاحتياطية العشرة على ورقة (مرة واحدة).
4. **عند كل دخول**، كتابة الرمز المكون من 6 أرقام الذي يعرضه التطبيق.

## ما تحتاجه { #prerequis }

- هاتف **أندرويد** أو **آيفون** (بنظام iOS 16 أو أحدث)؛
- تطبيق **Google Authenticator** المجاني (انظر [الخطوة 1](installer/index.md))؛
- ضبط ساعة الهاتف على **الوضع التلقائي**؛
- على الحاسوب: **Java 8 update 60** أو إصدار أحدث؛
- **ورقة وقلم** لتسجيل الرموز الاحتياطية.

!!! warning "يجب أن تكون ساعة الهاتف مضبوطة"
    يعتمد الرمز على الوقت. إذا كانت ساعة الهاتف غير مضبوطة، ولو بدقيقة أو دقيقتين، سيتم رفض الرمز.

### ضبط الساعة على الوضع التلقائي { #prerequis-1 }

- **أندرويد**: الإعدادات ← النظام ← التاريخ والوقت ← فعّل **التاريخ والوقت التلقائيان** (قد يختلف الاسم حسب نوع الهاتف).
- **آيفون**: الإعدادات ← عام ← التاريخ والوقت ← فعّل **الضبط تلقائياً**.

!!! darija "بالدارجة"
    شوف واش الساعة ديال التيليفون مريگلة أوطوماتيكياً. إلا كانت الساعة مضبوطة، الكود غادي يتقبل بلا مشكل.
