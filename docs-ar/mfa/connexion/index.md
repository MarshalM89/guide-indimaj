# الدخول اليومي

## الدخول في المرات القادمة { #connexion }

في **كل مرة** تدخل فيها إلى INDIM@J، تظهر نافذة **Vérification MFA** بعد كلمة المرور.

<figure markdown="span">
  ![نافذة «Vérification MFA»](../img/verification-mfa.png){ width="560" }
  <figcaption>نافذة «Vérification MFA»</figcaption>
</figure>

1. افتح تطبيق **Google Authenticator** على هاتفك.
2. اقرأ الرمز المكون من 6 أرقام.
3. اكتبه في خانة **Saisie du Code Authenticator**.
4. اضغط على **Verifier Code MFA**.

!!! info "لا حاجة للإنترنت على الهاتف"
    يعمل تطبيق Google Authenticator حتى بدون إنترنت أو شبكة الهاتف.

## هاتفك ليس معك؟ استعمل رمزاً احتياطياً { #secours }

1. في نافذة **Vérification MFA**، اضغط على الرابط الأزرق **Appuyez ici si vous avez des problemes avec votre code MFA**.
2. تظهر نافذة **Saisie d'un Code Secours**.
3. اكتب **رمزاً واحداً** من رموزك الاحتياطية كما هو مكتوب على الورقة تماماً.
4. اضغط على **Verifier Code Secours**.
5. اشطب هذا الرمز على الورقة: لن يعمل مرة أخرى.

<figure markdown="span">
  ![نافذة «Saisie d'un Code Secours»: يظهر عدد الرموز المتبقية باللون الأزرق](../img/saisie-code-secours.png){ width="560" }
  <figcaption>نافذة «Saisie d'un Code Secours»: يظهر عدد الرموز المتبقية باللون الأزرق</figcaption>
</figure>

!!! warning "بقيت لديك رموز قليلة؟"
    تُبيّن النافذة عدد الرموز المتبقية. عندما يتبقى القليل منها، أو إذا لم يعد هاتفك معك، اطلب إعادة التهيئة (انظر [«في حالة وجود مشكل»](../assistance/index.md)).

!!! darija "بالدارجة"
    إلا نسيتي التيليفون فالدار، دخل بواحد من الكودات اللي كاتبين فالورقة، ومن بعد شطب عليه باش ما تعاودش تستعملو.
