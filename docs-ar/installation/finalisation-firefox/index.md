# المرحلة 4 — إتمام إعداد Firefox

!!! info "إذا كنت تستعمل Basilisk"
    طبّق إعدادات هذه المرحلة في Basilisk أيضاً.

## الخطوة 15 — السماح بالنوافذ المنبثقة { #etape-15 }

<figure markdown="span">
  ![النوافذ المنبثقة](popup.png){ width="760" }
  <figcaption>Firefox › Options › Contenu</figcaption>
</figure>

1. في Firefox، افتح القائمة **☰** ثم **Options**.
2. اضغط على **Contenu**.
3. أزل العلامة من خانة **Bloquer les fenêtres popup**.

!!! warning "مهم"
    بدون هذا الخيار، لا يمكن عرض مطبوعات INDIM@J (les éditions).

## الخطوة 16 — إضافة INDIM@J إلى استثناءات Firefox { #etape-16 }

<figure markdown="span">
  ![استثناءات Firefox](exceptions-firefox.png){ width="760" }
  <figcaption>Firefox › Options › Sécurité</figcaption>
</figure>

1. في **Options** الخاصة بـ Firefox، اضغط على **Sécurité**.
2. مقابل **Prévenir lorsque les sites essaient d'installer des modules complémentaires**، اضغط على **Exceptions…**
3. اكتب **https://indimaj.tgr.gov.ma** ثم اضغط على **Autoriser**.
4. اضغط على **Enregistrer les modifications**.

!!! info "مستعملو INDIM@J Partenaire"
    اكتب نفس العنوان **https://indimaj.tgr.gov.ma**: فهو يشمل أيضاً رابط الدخول إلى INDIM@J Partenaire (`https://indimaj.tgr.gov.ma/forms/frmservlet?config=INDJPAR`). لا داعي لإضافة عنوان ثانٍ.

<figure markdown="span">
  ![الموقع مسموح به](exceptions-resultat.png){ width="560" }
  <figcaption>النتيجة المنتظرة: يظهر الموقع في اللائحة بالحالة «Autoriser»</figcaption>
</figure>
