# التحقق النهائي

ضع علامة على كل نقطة تم التحقق منها. عندما تكون جميع النقاط محددة، يكون الحاسوب جاهزاً للدخول إلى INDIM@J.

- [ ] Firefox 52 ESR مثبّت
- [ ] تحديثات Firefox متوقفة
- [ ] الشهادة منشأة على https://certificat.tgr.gov.ma
- [ ] الشهادة محفوظة (.p12) وكلمة مرورها مسجلة
- [ ] Java 8 بنسخة 32 bits مثبّت (`jre-8u60-windows-i586.exe`)
- [ ] مجموعة Utilisateurs لها صلاحية الكتابة في مجلد Java
- [ ] https://indimaj.tgr.gov.ma ضمن المواقع المسموح بها في Java (صالح أيضاً لـ INDIM@J Partenaire)
- [ ] الشهادة مستوردة إلى Java (Authentification du client)
- [ ] تم التحقق من إعدادات الأمان المتقدمة في Java
- [ ] تحديثات Java متوقفة
- [ ] النوافذ المنبثقة مسموح بها في Firefox
- [ ] https://indimaj.tgr.gov.ma ضمن استثناءات Firefox (صالح أيضاً لـ INDIM@J Partenaire)
