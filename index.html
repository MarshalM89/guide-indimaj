    Guide d'utilisation INDIM@J¶

    Ce guide accompagne les utilisateurs d'INDIM@J pour préparer leur poste de travail, renouveler leur certificat d'accès, activer la double authentification (MFA) et résoudre les problèmes les plus courants.

    Certificat expiré ?

    Si Firefox affiche « Échec de la connexion sécurisée » avec le code SSL_ERROR_EXPIRED_CERT_ALERT, votre certificat a expiré. Suivez le guide Renouvellement du certificat.

    Adresses de connexion

    • INDIM@J : https://indimaj.tgr.gov.ma/
    • INDIM@J Partenaire : https://indimaj.tgr.gov.ma/forms/frmservlet?config=INDJPAR
