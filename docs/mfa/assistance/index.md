# En cas de problème : qui contacter ?

Dans les cas suivants, la double authentification de votre compte doit être **réinitialisée** :

- téléphone perdu, volé, changé ou remis à zéro ;
- application Google Authenticator supprimée ;
- feuille de codes de secours perdue ;
- tous les codes de secours utilisés.

Selon l'organisation de votre ministère :

- contactez le **correspondant MFA** de votre ministère, qui transmettra votre demande ;
- ou écrivez directement à l'équipe INDIM@J : [equipe_indimaj@tgr.gov.ma](mailto:equipe_indimaj@tgr.gov.ma).

Indiquez dans votre message :

- vos nom et prénom ;
- votre identifiant INDIM@J ;
- votre ministère ou département ;
- le problème rencontré (par exemple : « téléphone perdu »).

Après la réinitialisation, refaites simplement l'[étape 2](../activation/index.md) à votre prochaine connexion, avec un nouveau QR code.

!!! danger "Ne communiquez jamais vos codes"
    Ne donnez jamais votre code à 6 chiffres ni vos codes de secours, même à un collègue, par téléphone ou par e-mail.
