# Étape 1 — Installer Google Authenticator

Choisissez le lien qui correspond à votre téléphone :

[:material-google-play: Google Play — Android](https://play.google.com/store/apps/details?id=com.google.android.apps.authenticator2){ .md-button .md-button--primary target="_blank" }
[:material-apple: App Store — iPhone](https://apps.apple.com/app/google-authenticator/id388497605){ .md-button .md-button--primary target="_blank" }

Vous pouvez aussi l'installer vous-même :

1. Sur votre téléphone, ouvrez **Play Store** (Android) ou **App Store** (iPhone).
2. Dans la recherche, tapez **Google Authenticator**.
3. Vérifiez que l'éditeur est bien **Google LLC**, puis appuyez sur **Installer** (ou **Obtenir** sur iPhone).
4. Ouvrez l'application. Si elle vous propose de vous connecter à un compte Google, ce n'est pas obligatoire pour INDIM@J.

!!! warning "Attention aux imitations"
    L'application est gratuite. Si on vous demande de payer, ce n'est pas la bonne : vérifiez que l'éditeur est **Google LLC**.
