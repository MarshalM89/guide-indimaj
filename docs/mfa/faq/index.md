# Questions fréquentes

??? question "Mon code est refusé. Que faire ?"
    - Le code a peut-être changé pendant que vous le tapiez : attendez le code suivant et tapez-le sans tarder.
    - Vérifiez que l'heure de votre téléphone est en mode automatique (voir [« Ce qu'il vous faut »](../index.md#ce-quil-vous-faut)).
    - Tapez les 6 chiffres sans espace.

??? question "Dois-je taper un code à chaque connexion ?"
    Oui. À chaque connexion à INDIM@J, après le mot de passe, tapez le code affiché par l'application.

??? question "Mon téléphone doit-il être connecté à Internet ?"
    Non. Google Authenticator fonctionne sans Internet et sans réseau mobile. Internet n'est nécessaire que pour installer l'application.

??? question "L'application est-elle payante ?"
    Non, Google Authenticator est gratuite. Méfiez-vous des applications qui lui ressemblent : vérifiez que l'éditeur est **Google LLC**.

??? question "J'ai changé de téléphone, ou je l'ai perdu."
    Connectez-vous avec un code de secours en attendant, puis demandez la réinitialisation de votre double authentification (voir [« En cas de problème »](../assistance/index.md)). Vous scannerez ensuite un nouveau QR code avec votre nouveau téléphone.

??? question "J'ai supprimé l'application par erreur."
    Connectez-vous avec un code de secours, puis demandez une réinitialisation (voir [« En cas de problème »](../assistance/index.md)).

??? question "J'ai perdu ma feuille de codes de secours."
    Vous pouvez continuer à vous connecter avec votre téléphone. Demandez quand même une réinitialisation pour obtenir de nouveaux codes : sans eux, vous seriez bloqué en cas de perte du téléphone.

??? question "Mon code de secours est refusé."
    - Vérifiez que vous ne l'avez pas déjà utilisé.
    - Attention aux caractères qui se ressemblent : le chiffre **0** et la lettre **O**, le chiffre **1** et la lettre **I**.
    - Tapez le code exactement comme il est écrit sur votre feuille.

??? question "Puis-je photographier le QR code ou mes codes de secours ?"
    Non. Ne photographiez pas le QR code et ne le partagez pas. Pour les codes de secours, préférez une feuille de papier rangée en lieu sûr : une photo dans votre téléphone serait perdue en même temps que lui.

??? question "Je n'ai pas de smartphone."
    Google Authenticator ne fonctionne que sur un smartphone (Android ou iPhone). Contactez le correspondant MFA de votre ministère ou l'équipe INDIM@J.

??? question "Quelle version de Java faut-il ?"
    **Java 8 update 60** ou une version plus récente. Pour vérifier votre version, consultez la rubrique [Dépannage](../../depannage/index.md) du guide INDIM@J.
