# Vérification finale

Cochez chaque point vérifié. Lorsque tous les points sont cochés, le poste est prêt pour la connexion à INDIM@J.

- [ ] Firefox 52 ESR est installé
- [ ] Les mises à jour de Firefox sont désactivées
- [ ] Le certificat est généré sur https://certificat.tgr.gov.ma
- [ ] Le certificat est sauvegardé (.p12) et son mot de passe est noté
- [ ] Java 8 32 bits est installé (`jre-8u60-windows-i586.exe`)
- [ ] Le groupe Utilisateurs a le droit d'écriture sur le dossier Java
- [ ] https://indimaj.tgr.gov.ma figure dans les sites autorisés par Java (valable aussi pour INDIM@J Partenaire)
- [ ] Le certificat est importé dans Java (Authentification du client)
- [ ] Les paramètres de sécurité avancés de Java sont vérifiés
- [ ] Les mises à jour de Java sont désactivées
- [ ] Les fenêtres popup sont autorisées dans Firefox
- [ ] https://indimaj.tgr.gov.ma figure dans les exceptions de Firefox (valable aussi pour INDIM@J Partenaire)

!!! info "Adresses de connexion"
    - **INDIM@J** : [https://indimaj.tgr.gov.ma/](https://indimaj.tgr.gov.ma/){ target="_blank" }
    - **INDIM@J Partenaire** : [https://indimaj.tgr.gov.ma/forms/frmservlet?config=INDJPAR](https://indimaj.tgr.gov.ma/forms/frmservlet?config=INDJPAR){ target="_blank" }
