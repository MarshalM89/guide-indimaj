    Installation du poste¶

    Cette partie décrit l'installation et la configuration d'un poste de travail pour accéder à INDIM@J, en quatre phases.

    Avant de commencer

    • Télécharger Firefox Setup 52.0.1esr.exe et jre-8u60-windows-i586.exe depuis le dossier Google Drive des fichiers d'installation.
    • Disposer des droits administrateur sur le poste.
    • Disposer de votre login INDIM@J (utilisé pour générer le certificat).

    Fichiers d'installation Documentation INDIM@J

    Les quatre phases¶

    Phase Contenu Étapes
    Phase 1 — Navigateurs Installer Firefox 52 ESR et, si besoin, Basilisk 1 à 3
    Phase 2 — Certificat Créer et sauvegarder le certificat d'accès 4 à 7
    Phase 3 — Java Installer et configurer Java, importer le certificat 8 à 14
    Phase 4 — Finalisation de Firefox Autoriser les fenêtres popup et ajouter les exceptions 15 et 16

    Une fois l'installation terminée, contrôlez le poste avec la liste de vérification finale.

    Utilisateurs d'INDIM@J Partenaire

    L'installation du poste est identique pour INDIM@J Partenaire. Seul le lien de connexion diffère : https://indimaj.tgr.gov.ma/forms/frmservlet?config=INDJPAR

    Navigateur alternatif : Basilisk

    INDIM@J fonctionne aussi avec le navigateur Basilisk (32 bits). Firefox 52 ESR reste indispensable pour créer le certificat. Voir l'étape 3 (facultative).
